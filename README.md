# Conversor de Unidades

## Descripción del programa

Este programa fue desarrollado para convertir unidades de forma sencilla mediante una interfaz gráfica creada en **C# con Windows Forms**. El usuario escribe un valor, selecciona el tipo de conversión y presiona el botón **Convertir** para obtener el resultado.

El sistema permite realizar dos conversiones:

- Kilómetros a millas.
- Grados Celsius a grados Fahrenheit.

También se incluye una validación para comprobar que el valor ingresado sea numérico antes de realizar la conversión.

## Funcionalidades

- Convertir kilómetros a millas.
- Convertir grados Celsius a Fahrenheit.
- Validar la entrada de datos.
- Mostrar el resultado de la conversión.

## Tecnologías utilizadas

- C#
- Windows Forms (.NET)
- Visual Studio 2022
